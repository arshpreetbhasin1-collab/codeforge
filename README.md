# CodeForge

In-progress coding practice and problem-solving platform, aiming to build a better alternative to LeetCode.

## Overview

CodeForge is an ongoing personal project to build a coding practice platform: problem sets, a code editor/runner, and progress tracking, with the goal of improving on the experience of existing platforms like LeetCode.

## Tech stack

Next.js, TypeScript, Tailwind CSS, Supabase.

## Getting started

Clone the repo, run `npm install`, set up the required environment variables locally, then run `npm run dev`.

## Environment variables

Requires Supabase project keys, kept in a local `.env.local` file which is gitignored and never committed.

## Project status

In active development, not yet feature-complete.
